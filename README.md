# 운행노트

`index.html`을 브라우저로 열어 사용합니다. 설치나 외부 라이브러리 없이 동작합니다.

- 달력에서 날짜 선택 → 운행 기록 추가, 수정, 삭제
- 대리 운전 / 탁송 운전, 출발지 / 경유지 / 도착지, 이용 앱 입력
- 실수입 = 운행비 + 팁 − 운행비의 20% − 톨비 − 대중교통비
- 수수료는 운행별 원 단위 반올림, 팁에는 수수료 미적용
- 달력에 표시한 월의 합계와 선택한 날짜의 일지 표시
- 현재 브라우저의 localStorage에 자동 저장
- 드라이브 메뉴로 전체 자료 백업 및 복원

불러오기는 확인 후 기존 전체 자료를 교체합니다. 먼저 JSON 저장으로 백업하세요. 브라우저 저장 자료는 다른 기기에 자동으로 동기화되지 않습니다. 파일을 직접 여는 환경에서 브라우저 저장을 지원하지 않으면 웹 서버로 실행하세요.

Python이 있다면 이 폴더에서 `python3 -m http.server 8090`을 실행하고 `http://localhost:8090`에 접속할 수 있습니다.

## Google 드라이브

화면 위의 드라이브 저장 / 불러오기 버튼으로 Google 계정에 연결합니다. 저장할 때마다 내 드라이브에 날짜와 시간이 포함된 JSON 백업을 새로 생성합니다. 이 앱에서 만든 백업을 최신순으로 선택해 복원할 수 있습니다. 자동 동기화가 아니므로 변경 후 저장 버튼을 누르세요. 연결 토큰은 메모리에만 유지되며 새로고침하거나 만료되면 다시 연결합니다.

Google Cloud에서 제공한 웹 애플리케이션 클라이언트 ID의 프로젝트에 Google Drive API를 활성화해야 합니다. OAuth 클라이언트의 승인된 JavaScript 원본에 `http://localhost:8000`을 등록하세요. 테스트 상태인 경우 사용하는 Google 계정을 테스트 사용자에 추가하세요. 다른 주소로 접속한다면 해당 원본을 등록해야 하며 localhost 외에는 HTTPS가 필요합니다. 클라이언트 보안 비밀번호는 필요하지 않습니다.

권한: `https://www.googleapis.com/auth/drive.file` (앱에서 만든 파일 접근).
공식 설정 안내: https://developers.google.com/identity/oauth2/web/guides/get-google-api-clientid

화면 구성: 달력 → 날짜 선택 시 일별 화면(#day/YYYY-MM-DD) → 상단 달력으로 돌아가기. 브라우저 뒤로 가기도 지원합니다. Google 드라이브 메뉴는 달력 화면의 운행 기록 버튼 왼쪽에 있습니다.
